# V0.3 发布范围

## 已完成

- Twilio WhatsApp 单一生产渠道
- 入站签名校验和 `MessageSid` 持久化去重
- 联系人、对话历史、人工接管和送达回执
- 八阶段销售管道、变更审计和人工锁定
- AI 内部摘要、资格分、冷热度、缺失资料和下一步行动
- 销售任务队列：待回复、人工复核、到期跟进、重点客户、长期未推进客户
- RAG 来源、相似度和置信度内部追踪
- 知识库健康检查及内部成本文件隔离
- 生产配置预检、运行数据备份、哈希校验恢复和无密钥发布包

## 明确不包含

- Meta Cloud API、Facebook Messenger、Chatwoot
- 未经人工批准的主动 WhatsApp 营销或自动追单
- 自动签合同、自动承诺审批、自动给出未批准价格
- 自动修改 Twilio、DNS、Nginx 或生产服务器

## 外部资料边界

当前知识库没有独立、经批准的 QHC 文件。系统不会猜测 QHC 含义或政策；遇到相关问题应说明需要确认并进入人工复核。提供正式资料后可通过“教模型”页面加入知识库并重新索引。

## 上线决定

候选版本完成后仍保持本地状态。只有负责人明确确认正式上线，才进入服务器备份、候选部署和真实 Twilio 验证流程。
